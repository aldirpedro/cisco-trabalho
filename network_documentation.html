1. Configuração de Serviço DNS

O que é DNS?

O Domain Name System (DNS) é um serviço que traduz nomes de domínio legíveis (como www.example.com) em endereços IP (como 192.168.1.1). É essencial para a navegação na internet.

Detalhes da Imagem 1: Interface de Serviços DNS

Esta imagem mostra a aba "Services" do Cisco Packet Tracer, onde está configurado o servidor DNS. Os serviços visíveis incluem:

  • HTTP: Protocolo de transferência de hipertexto
  • DHCP: Protocolo de configuração dinâmica de hospedeiro
  • TFTP: Protocolo trivial de transferência de arquivo
  • DNS: Sistema de nomes de domínio (configurado)
  • Syslog: Sistema de registros de eventos
  • AAA: Authentication, Authorization and Accounting

Configurações principais: O servidor DNS está ativo e configurado para resolver nomes de domínio. A entrada "Add rows" mostra um endereço IP 192.168.7.6, indicando que foi adicionado um registro DNS.

2. Redes Wireless (WiFi) Configuradas

Estrutura de Redes WiFi

O projeto utiliza três redes WiFi separadas para diferentes propósitos, cada uma com suas próprias configurações de segurança e banda de frequência.

WiFi PROFESSORES

Banda: 2.4 GHz

Modo: Infrastructure

Tipo de Rede: Mixed B/G/N

Segurança: WPA2-PSK

Rede dedicada para uso dos docentes com autenticação forte.

WiFi CONVIDADOS

Banda: 2.4 GHz

Tipo de Rede: Mixed B/G/N

Segurança: WPA2-PSK

Cobertura: 256 metros

Rede aberta mas segura para visitantes e convidados da instituição.

WiFi ALUNOS

Banda: 2.4 GHz

Tipo de Rede: Mixed B/G/N

Segurança: WPA2-PSK

Cobertura: 256 metros

Rede exclusiva para acesso dos alunos com autenticação WPA2.

Especificações Técnicas das Redes WiFi
  • Padrão 802.11: Suporte a B/G/N garante compatibilidade com diversos dispositivos
  • Frequência 2.4 GHz: Banda mais comum, maior alcance e compatibilidade
  • WPA2-PSK: Encriptação AES, padrão de segurança atual mais robusto
  • Cobertura de 256m: Ideal para ambientes educacionais de médio porte
  • Segregação de rede: Três VLANs diferentes para diferentes grupos de usuários

4. Topologia Lógica da Rede - Visão Geral

Arquitetura da Rede

A topologia lógica mostra como os componentes de rede estão interconectados e como o tráfego de dados flui através da infraestrutura.

Componentes Principais da Topologia
  • Switch Central (2960): Núcleo da rede, conecta todos os dispositivos
  • Servidores: Incluem servidor web, email, DHCP, DNS e FTP
  • Router (2911): Conecta a rede interna à internet
  • WiFi Access Points: Três pontos de acesso para as redes wireless
  • Clientes: PCs e laptops conectados via cabo ou WiFi
  • Impressoras: Conectadas à rede para uso compartilhado

7. Configuração do Servidor DHCP

Dynamic Host Configuration Protocol (DHCP)

O DHCP é responsável por atribuir automaticamente endereços IP aos dispositivos que se conectam à rede.

Parâmetros DHCP Configurados
  • IP Configuration: IP estático 192.168.7.4 para o próprio servidor
  • Subnet Mask: 255.255.255.0
  • Default Gateway: 192.168.7.2
  • DNS Server: 192.168.7.2
  • DHCP Pool: Range de IPs para distribuição dinâmica
  • Lease Time: Tempo de concessão do IP

Configuração PyV: Ambos IPv4 e IPv6 estão configurados para suportar ambos os protocolos de internet.
