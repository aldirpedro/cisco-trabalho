Como funcionam os protocolos (visão educacional)

DNS

Domain Name System – converte nomes amigáveis (ex: epf.com) em endereços IP. No projeto, o servidor DNS em 192.168.7.2 possui um registro A que aponta epf.com → 192.168.7.6 (servidor de email).

consulta: www.escola.pt? → 192.168.7.5 (web)

DHCP

Dynamic Host Configuration Protocol – fornece IP, máscara, gateway e DNS automaticamente aos clientes. Processo DORA (Discover, Offer, Request, Acknowledge).

Cliente .10 obteve IP via servidor 192.168.7.4

HTTP / Web

O servidor web (192.168.7.5) entrega páginas utilizando o protocolo HTTP (porta 80). Quando um cliente digita o nome resolvido pelo DNS, o servidor responde com o conteúdo HTML.

E-mail (SMTP, POP3)

SMTP (25) para envio; POP3 (110) ou IMAP (143) para recebimento. O servidor de email 192.168.7.6 gerencia as contas locais.

FTP

Transferência de ficheiros com autenticação. Duas portas: 21 (comandos) e 20 (dados). Útil para partilha de material didático.

Wi‑Fi WPA2

As três redes utilizam WPA2-PSK com criptografia AES. Cada uma opera nos canais 6 (2.4 GHz) e 112 (5 GHz), cobertura nominal de 250 m.

🖧 Cisco Packet Tracer — ambiente de simulação

O Packet Tracer permite modelar redes com equipamentos Cisco, servidores e clientes. Neste projeto foram utilizados: roteador 2911, switch 2960, três access points, seis servidores e múltiplos laptops (Miguel, Aldir, gang gang…). Os testes de ping comprovam conectividade total (0% perda).
