O projeto implementa uma infraestrutura de rede completa utilizando Cisco Packet Tracer, incluindo:

Camada de Acesso: 3 Access Points wireless com cobertura de 256 metros cada
Camada de Distribuição: Switch Cisco 2960 com 24 portas Gigabit
Camada de Núcleo: Router Cisco 2911 com conectividade internet
Camada de Aplicação: 7 servidores especializados em diferentes serviços
