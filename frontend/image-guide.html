📸 Guia de Imagens do Projeto Cisco Network

Este guia ensina como capturar e inserir screenshots do Cisco Packet Tracer no site.

1. Criar Pasta

frontend/
├── images/        ← Criar esta pasta
├── index.html
├── servers.html
└── css/

2. Tirar Screenshots (6 imagens)

#O QuêNome do ArquivoInstruções
1Topologia Completatopology.pngAbra o Packet Tracer e capture a visão geral
2Configuração DNSdns-config.pngServices no servidor DNS
3Configuração DHCPdhcp-config.pngServices no servidor DHCP
4Redes WiFiwifi-config.pngConfiguração dos access points
5Monitor Wirelesswireless-monitor.pngMostra as três redes
6Testes de Pingping-test.pngPrompt de comando do PC

3. Salvar Imagens

Use Print Screen e cole no Paint. Salve em frontend/images/ como PNG.

4. Adicionar ao HTML

<div class="image-container">
    <img src="images/topology.png" alt="Topologia Geral" style="width: 100%; border-radius: 8px;">
    <p><strong>Topologia Geral</strong></p>
</div>

Checklist

  • Criar pasta frontend/images/
  • Capturar topology.png
  • Capturar dns-config.png
  • Capturar dhcp-config.png
  • Capturar wifi-config.png
  • Capturar wireless-monitor.png
  • Capturar ping-test.png
  • Salvar tudo em images/
  • Editar tags <img> em servers.html
  • Abrir index.html e verificar

Dicas Rápidas

  • Use PNG em alta resolução (>=800x600px).
  • Nomes em minúsculas com hífen.
  • Adicione style="width:100%;max-width:100%;" às imagens.
  • Comprimir se tiver tamanho grande.
