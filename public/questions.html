❓ Perguntas & Respostas

Responda a estas questões educacionais sobre redes e servidores para consolidar o seu conhecimento.

1️⃣ Como DHCP, DNS, WEB e EMAIL trabalham em conjunto? ▼

Resposta:

Quando um utilizador liga um computador à rede:

  1. DHCP: Atribui um endereço IP automaticamente
  2. DNS: Permite resolver nomes de domínio (ex: www.escola.pt) para IPs
  3. WEB: O utilizador acede a websites usando um navegador
  4. EMAIL: Pode enviar e receber emails através de servidores SMTP/POP3

Exemplo prático:

  • PC recebe IP 192.168.1.100 (DHCP)
  • Utilizador digita "www.escola.pt" no navegador
  • DNS traduz para 192.168.1.50
  • Navegador conecta-se ao servidor WEB em 192.168.1.50 e recebe o HTML
  • Utilizador acede webmail e envia um email
  • Email é encaminhado através do servidor SMTP
2️⃣ Qual é a importância prática do FTP numa escola? ▼

Resposta:

O FTP é fundamental para a distribuição de materiais educacionais e recolha de trabalhos dos alunos:

  • Distribuição de Materiais: Professores colocam aulas em PDF, vídeos e exercícios num servidor FTP
  • Acesso Controlado: Alunos autenticam-se com utilizador/password para descarregar materiais
  • Entrega de Trabalhos: Alunos podem fazer upload dos trabalhos realizados
  • Backup Centralizado: Todos os ficheiros da escola estão num único servidor
  • Sem Necessidade de Email: Ficheiros grandes podem ser partilhados via FTP sem sobrecarregar o email

Segurança: Utilizar SFTP (FTP seguro) com encriptação é recomendado, especialmente com dados sensíveis de alunos.

3️⃣ Quais são as consequências da falha do servidor DNS? ▼

Resposta:

Se o servidor DNS falhar, as consequências são graves:

⚠️ Impacto:
  • Impossível acessar websites por nome: Utilizadores não conseguem aceder a www.google.com, www.escola.pt, etc.
  • Email não funciona: Os clientes de email não conseguem conectar-se aos servidores (precisam de IPs)
  • Apenas IPs funcionam: Se souber o IP (ex: 192.168.1.50), consegue aceder direto
  • Serviços de rede degradados: Muitas aplicações dependem de DNS (chamadas LDAP, autenticação, etc.)

Solução:

  • Ter um servidor DNS redundante (backup)
  • Usar DNS externo (ex: 8.8.8.8 do Google) como fallback
  • Monitorizar a disponibilidade do DNS continuamente
4️⃣ Quando usar IP estático em vez de DHCP? ▼

Resposta:

Usar IP Estático para:

  • Servidores: Web, FTP, DNS, Email — precisam de IPs fixos para serem acessíveis
  • Impressoras de Rede: Utilizadores precisam de saber o IP para imprimir
  • Routers/Gateways: Precisam de IP fixo como ponto de acesso predefinido
  • Câmaras IP: Vigilância contínua necessita IP permanente
  • Computadores Administrativos: Facilita acesso SSH/RDP para administração

Usar DHCP para:

  • Computadores dos Alunos: Reduz configuração manual
  • Laptops/Tablets: Conectam em diferentes redes com facilidade
  • Dispositivos Móveis: WiFi é mais prático com DHCP
  • Ambientes com muitos utilizadores: Evita conflitos de IPs

Boas Práticas:

  • Configurar servidores com IP estático no router (ex: 192.168.1.10)
  • Documentar IPs estáticos para referência
  • Utilizar reservas de DHCP para alguns clientes críticos (imprime, etc.)
5️⃣ Qual é a diferença entre POP3 e IMAP? ▼

Resposta:

Característica POP3 IMAP
Armazenamento Descarrega para cliente Fica no servidor
Múltiplos Dispositivos ❌ Não sincroniza ✅ Sincroniza automaticamente
Acesso Offline ✅ Sim (ficheiros locais) ❌ Não (precisa conexão)
Uso de Banda Menor Maior
Ideal para: Desktop único Múltiplos dispositivos/Mobile

Exemplo:

  • POP3: Você baixa um email no Outlook. O email é apagado do servidor. Se entrar no carro com o telemóvel, o email não está lá.
  • IMAP: Você vê um email no Outlook. Se entrar no carro e abrir o Gmail, o mesmo email está lá com as mesmas pastas e status.
6️⃣ O que é um "lease time" em DHCP? ▼

Resposta:

O lease time é o tempo durante o qual um cliente pode usar um endereço IP atribuído pelo servidor DHCP.

  • Exemplo: Lease time de 24 horas significa que o PC pode usar o IP por 24 horas
  • Após expira: O cliente entra novamente em contacto com DHCP para renovar ou obter um novo IP
  • Valores típicos: 1 hora, 8 horas, 24 horas, 7 dias

Vantagens:

  • Reutilização de IPs quando dispositivos se desligam
  • Evita "vazamento" de IPs
  • Permite mudanças na rede (ex: expandir para novo sub-net)

Nota: Valores curtos (1h) são usados em redes com muitos dispositivos móveis. Valores longos (7 dias) em redes estáveis.
