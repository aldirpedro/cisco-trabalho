�️ O Que é Cisco Packet Tracer?

Cisco Packet Tracer é um simulador de rede desenvolvido pela Cisco Systems que permite:

✓ Criar Topologias de Rede: Desenhar redes com routers, switches, computadores e outros dispositivos sem precisar de hardware real


✓ Configurar Dispositivos: Acessar CLI (Command Line Interface) de routers e switches, aplicar configurações reais de networking


✓ Simular Comunicação: Verificar se os pacotes de dados conseguem passar de um ponto a outro da rede


✓ Testar Conectividade: Realizar testes de Ping, traceroute e outras ferramentas de diagnóstico


✓ Aprender Networking: Usar em ambientes educacionais para entender protocolos e topologias sem custo

🔧 Como Nossa Rede Foi Construída

1. Planejamento: Definimos uma arquitetura com 1 router, 1 switch central, 6 servidores especializados, 3 access points WiFi e múltiplos clientes

2. Adição de Dispositivos: Adicionamos cada dispositivo no Packet Tracer através da interface de drag-and-drop

3. Conexões: Conectamos os dispositivos com cabos Ethernet (para cabeados) e configuramos access points para wireless

4. Configuração de Servidores: Configuramos DNS, DHCP, Web, Email, FTP e outros serviços na aba "Services" de cada servidor

5. Testes: Usamos o comando Ping para verificar se a conectividade estava funcionando entre os dispositivos

📖 Explicação dos Servidores

Cada servidor tem um propósito específico na infraestrutura:

🌐 DNS Server

Traduz nomes (www.escola.pt) em números IP (192.168.7.5). Sem ele, você precisaria memorizar todos os números!

🔌 DHCP Server

Atribui IPs automaticamente. Quando você conecta um PC, o DHCP dá um endereço IP sem precisar configurar manualmente.

🌍 Web Server

Hospeda páginas web. Quando você digita um endereço no navegador, o web server responde com HTML/CSS.

✉️ Email Server

Gerencia emails. SMTP envia, POP3/IMAP recebem. Funciona como uma agência de correios digital.

📁 FTP Server

Transfere arquivos. Professores podem fazer upload de aulas, alunos fazem download de materiais.

⚙️ TFTP Server

FTP simplificado, sem autenticação. Usado para boot de dispositivos de rede e atualizações rápidas.
